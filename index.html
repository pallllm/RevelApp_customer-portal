WordPress + Next.js ハイブリッド構成

要件定義v1に基づき、WPの認証・設定管理とWebアプリの業務UIを連携します。

WordPress側

  • 認証（施設アカウント1ID）
  • 契約情報・サポート記事をCPT/ACFで管理
  • WP REST API + カスタムエンドポイント

Webアプリ側

  • Next.js + Tailwindでダッシュボードを構築
  • facility_idでデータを絞り込み表示
  • セルフモニタリング/工賃データの可視化

将来はGASやRevelApp本体DBとの直接連携、API仕様書の整備を予定しています。
